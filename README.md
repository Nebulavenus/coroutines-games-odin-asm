# Project

## Setup

### Prerequisites
- [Odin Compiler](https://odin-lang.org/)
- [SDL3](https://wiki.libsdl.org/SDL3/FrontPage) (included via Odin vendor)

### Building
To compile the project, first initialize the environment (on Windows):

    vcvarsall.bat x64

Then use the provided build script:

    .\build.ps1

To run the application:

    .\build.ps1 run
